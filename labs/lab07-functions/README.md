# Lab 07: 函式

## 🎯 目標

1. 學會定義和呼叫函式
2. 理解函式參數傳遞（傳值呼叫）
3. 練習函式的拆解與設計

## 📋 作業說明

### Part 1: 函式練習 (40%)

完成 `src/functions.c` 中的函式定義。

### Part 2: 函式追蹤 (30%)

在 `trace_answers.md` 中追蹤 `src/trace.c` 的執行流程，畫出 Call Stack 變化。

### Part 3: 函式設計 (30%)

完成 `src/design.c` 中的函式設計練習，將重複的程式碼重構為函式。
