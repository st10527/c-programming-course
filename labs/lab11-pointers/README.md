# Lab 11: 指標基礎

## 🎯 目標

1. 理解指標的概念（位址、取址、解參考）

## 📋 作業說明

### Part 1: 指標操作 (40%)

### Part 3: 指標應用 (30%)

完成 `src/applications.c` 中使用指標傳遞參數的函式。
