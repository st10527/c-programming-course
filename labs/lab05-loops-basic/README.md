# Lab 05: 迴圈基礎

## 🎯 目標

1. 熟悉 for、while、do-while 三種迴圈
2. 練習在紙上追蹤迴圈執行
3. 能正確處理迴圈邊界條件

## 📋 作業說明

### Part 1: 迴圈實作練習 (40%)

完成 `src/loops.c` 中的迴圈練習。

### Part 2: 迴圈追蹤 (40%)

在 `trace_answers.md` 中追蹤 `src/trace.c` 的執行過程，填寫變數值表格。

### Part 3: 預測輸出 (20%)

預測 `src/predict.c` 中每個迴圈的輸出。
