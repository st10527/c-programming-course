# Lab 08: 遞迴

## 🎯 目標

1. 理解遞迴的概念與執行過程
2. 學會設計遞迴函式（Base Case + Recursive Case）
3. 能夠手動追蹤遞迴的呼叫過程

## 📋 作業說明

### Part 1: 遞迴練習 (40%)

完成 `src/recursion.c` 中的遞迴函式。

### Part 2: 遞迴追蹤 (30%)

在 `trace_answers.md` 中追蹤 `src/trace.c` 的遞迴呼叫過程，畫出呼叫樹。

### Part 3: 遞迴除錯 (30%)

修正 `src/debug.c` 中錯誤的遞迴函式。
