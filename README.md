## 🎯 課程目標

培養學生具備：
1. **程式閱讀能力** - 能讀懂程式碼並追蹤執行流程
2. **邏輯思維能力** - 能將問題轉化為程式邏輯
3. **除錯分析能力** - 能找出程式錯誤並修正
4. **程式碼品味** - 能辨識好的與不好的程式碼
5. **AI 協作能力** - 能正確運用 AI 工具輔助開發
