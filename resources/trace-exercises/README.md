# 程式追蹤練習題庫

這個資料夾包含各種程式追蹤練習題，用於培養學生的「程式語感」。

## 使用方式

1. 閱讀程式碼
2. 在紙上追蹤變數值的變化
3. 預測程式輸出
4. 執行程式驗證答案

## 追蹤技巧

### 1. 變數值表格

```
| 步驟 | x | y | z |
|-----|---|---|---|
| 初始 | - | - | - |
| 第1行 | 5 | - | - |
| 第2行 | 5 | 10 | - |
| 第3行 | 5 | 10 | 15 |
```

### 2. 迴圈追蹤表格

```
| 迴圈次數 | i | condition | sum |
|---------|---|-----------|-----|
| 進入前 | 0 | 0<5 (T) | 0 |
| 第1次 | 0→1 | 1<5 (T) | 0 |
| 第2次 | 1→2 | 2<5 (T) | 1 |
| ... | | | |
```

### 3. 函式呼叫追蹤

```
main() 開始
    ├─ 呼叫 foo(5)
    │   └─ 回傳 10
    ├─ 呼叫 bar(10)
    │   ├─ 呼叫 foo(10)
    │   │   └─ 回傳 20
    │   └─ 回傳 25
    └─ 結束
```
