# AI 使用指南

## 🤖 本課程的 AI 使用規範

本課程認可 AI 是現代程式開發的重要工具，但我們的目標是培養你**獨立思考程式邏輯的能力**。

---

## ✅ 鼓勵使用 AI 的情況

### 1. 解釋錯誤訊息
```
「這個錯誤訊息是什麼意思？」
「為什麼會出現 segmentation fault？」
```

### 2. 學習概念
```
「指標和變數有什麼不同？」
「什麼時候應該用 while 而不是 for？」
```

### 3. 理解程式碼
```
「這段程式碼在做什麼？」
「為什麼這裡要用 & 運算子？」
```

### 4. 優化建議
```
「這段程式碼有什麼可以改進的地方？」
「這個寫法有什麼潛在問題？」
```

### 5. 除錯輔助
```
「我的程式輸出不對，可能是什麼原因？」
「這個邏輯哪裡有問題？」
```

## ❌ 禁止的情況

### 1. 考試
- 期中考、期末考完全禁止使用 AI
- 這是評量你獨立思考能力的時候

### 2. 直接複製程式碼
- 不要直接複製 AI 生成的程式碼而不理解
- 如果複製，必須能解釋每一行

### 3. 逃避思考
- 不要在嘗試之前就問 AI
- 先自己想過，真的卡住再尋求幫助

---

## 🎯 正確的學習方式

### 步驟 1：先自己嘗試
```
閱讀題目 → 思考解法 → 嘗試撰寫 → 測試
```

### 步驟 2：遇到問題時
```
先看錯誤訊息 → 檢查程式碼 → 查課程資料 → 問同學
```

### 步驟 3：真的卡住才用 AI
```
問具體的問題 → 理解 AI 的解釋 → 用自己的話重述 → 應用到程式中
```

## 💡 與 AI 協作的好習慣

### 1. 問「為什麼」而不是「怎麼寫」

```
❌ 「幫我寫一個計算階乘的函式」
✅ 「遞迴計算階乘時，為什麼需要基本情況？」
```

### 2. 讓 AI 解釋而不是直接給答案

```
❌ 「這題的答案是什麼？」
✅ 「我覺得答案是 X，這樣對嗎？為什麼？」
```

### 3. 驗證 AI 的回答

```
AI 也可能出錯！
永遠要用你學到的知識驗證 AI 的回答
```

## 🏆 我們的目標

學期結束後，你應該能夠：

1. **不用 AI** 就能讀懂一般的 C 程式
2. **不用 AI** 就能找出程式中的錯誤
3. **不用 AI** 就能寫出基本的 C 程式
4. **善用 AI** 提高開發效率
5. **判斷 AI** 生成的程式碼品質好壞

## ❓ 常見問題

**Q: 我可以用 ChatGPT 幫我寫作業嗎？**
A: 可以參考，但你必須理解每一行程式碼，並能在被詢問時解釋。

**Q: 用 GitHub Copilot 算作弊嗎？**
A: 不算，但請標註使用，並確保你理解程式碼。

**Q: 如果 AI 寫的比我好，為什麼還要學？**
A: 因為你需要能力判斷 AI 寫得好不好。沒有基礎就無法判斷。

**Q: 怎麼證明我沒有用 AI？**
A: 我們不要求證明。但考試會檢驗你的真實能力。
