### 投影片 2：需要的工具
1. VS Code（程式碼編輯器）
2. GCC（C 語言編譯器）
3. Git（版本控制）

### 投影片 3：編譯流程
```
原始碼 (.c)
    ↓ 預處理
    ↓ 編譯
    ↓ 組譯
    ↓ 連結
執行檔
```

### 投影片 4：基本指令
```bash
gcc hello.c -o hello  # 編譯
./hello               # 執行
```
