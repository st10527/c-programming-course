5. **二維陣列** (15 min)

6. **練習** (5 min)

### 關鍵程式碼片段

#### 片段 1：陣列基本操作
```c
int scores[5] = {85, 92, 78, 95, 88};

// 用迴圈走訪
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += scores[i];
}
double avg = sum / 5.0;
```
> 完整範例：examples/arrays.c

#### 片段 2：二維陣列
```c
int matrix[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 走訪二維陣列
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
```

## 🎓 講課 B：常見錯誤

### 簡報大綱

1. **記憶體佈局** (25 min)
   - **重點：陣列的陷阱**
   - 陣列在記憶體中是連續的
   - 用 sizeof 計算陣列大小
   - `sizeof(arr) / sizeof(arr[0])` 求長度

2. **陣列越界問題** (30 min)
   - C 語言不會自動檢查邊界
   - 越界讀寫的後果
   - Buffer Overflow 簡介

3. **Off-by-one 錯誤** (25 min)
   - 最後一個元素是 `arr[n-1]` 不是 `arr[n]`
   - 迴圈條件 `< n` 不是 `<= n`
   - 常見錯誤場景

4. **陣列作為函式參數** (30 min)
   - 陣列傳遞的是位址（不是複製）
   - 函式內修改陣列會影響原陣列
   - 必須同時傳遞陣列大小

5. **討論** (10 min)

### 關鍵程式碼片段

#### 片段 1：陣列越界
```c
int arr[5] = {1, 2, 3, 4, 5};

// ❌ 越界！索引 0-4 才合法
printf("%d\n", arr[5]);   // 未定義行為
arr[5] = 100;             // 可能覆蓋其他變數的記憶體！
```

#### 片段 2：陣列作為函式參數
```c
// 必須傳大小，因為函式內 sizeof 不正確
void print_array(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
}
```
> 完整範例：examples/array_errors.c

## 📎 常見問題

**Q: 陣列大小可以用變數嗎？**
A: C99 支援 VLA（Variable Length Array），但不是所有編譯器都支援。建議用常數定義大小：`#define SIZE 100`。

**Q: 為什麼索引從 0 開始？**
A: 因為陣列名稱其實是指向第一個元素的位址，索引代表「偏移量」。第一個元素偏移 0，所以是 `arr[0]`。

**Q: 陣列和指標有什麼關係？**
A: 陣列名稱在大多數情況下會被當作指向第一個元素的指標。這在第 13-14 週會詳細講解。
