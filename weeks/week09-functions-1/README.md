### 關鍵程式碼片段

#### 片段 1：函式定義與呼叫
```c
// 函式定義
int add(int a, int b) {
    return a + b;
}

// 函式呼叫
int result = add(3, 5);  // result = 8
```
> 完整範例：examples/functions.c

#### 片段 2：傳值呼叫
```c
void try_to_change(int x) {
    x = 100;  // 只改了複製品，原來的不受影響
}

int main() {
    int n = 5;
    try_to_change(n);
    printf("n = %d\n", n);  // 還是 5！
}
```

#### 片段 3：函式原型
```c
// 先宣告（放在 main 前面）
int max(int a, int b);

int main() {
    printf("%d\n", max(3, 7));  // 可以呼叫了
    return 0;
}

// 後面才定義
int max(int a, int b) {
    return (a > b) ? a : b;
}
```

## 🎓 講課 B：呼叫追蹤

### 簡報大綱

1. **Stack Frame 概念** (30 min)
   - **重點：理解函式呼叫的記憶體**
   - 每次呼叫函式會產生新的 Stack Frame
   - Stack Frame 包含：參數、區域變數、返回地址
   - 函式結束時 Stack Frame 被移除

2. **區域變數的生命週期** (25 min)
   - 函式內宣告的變數只在函式內有效
   - 函式結束後區域變數消失
   - 不同函式可以有同名的區域變數

3. **Call Stack 視覺化** (40 min)
   - 畫出 Call Stack 的變化
   - 追蹤多層函式呼叫
   - main → funcA → funcB 的執行過程

4. **課堂追蹤練習** (20 min)
   - 帶著學生追蹤函式呼叫
   - 畫 Stack Frame

5. **討論** (5 min)

### 關鍵程式碼片段

#### 片段 1：Stack Frame 視覺化
```c
int multiply(int x, int y) {
    int result = x * y;
    return result;
}

int main() {
    int a = 3, b = 4;
    int c = multiply(a, b);
}
```
> 完整範例：examples/call_stack.c

```

┌─────────────────┐

```

## 📎 常見問題

**Q: 為什麼在函式內改參數，外面的值不會變？**
A: 因為 C 語言使用「傳值呼叫」，函式收到的是值的複製品。要修改外面的變數，需要用指標（第 13 週會教）。

**Q: 函式一定要有 return 嗎？**
A: 如果回傳型態是 `void`，不需要 return（或寫 `return;`）。如果有回傳型態（如 `int`），一定要 return 一個值。

**Q: 可以回傳多個值嗎？**
A: C 語言的 return 只能回傳一個值。要「回傳多個值」，可以用指標參數或結構體（這些之後會教）。
