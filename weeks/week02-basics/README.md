## 🎓 講課 A：C 程式結構

### 簡報大綱

1. **程式結構解析** (30 min)
   - 前處理指令 `#include`
   - `main()` 函式
   - 大括號與程式區塊
   - 分號的重要性

2. **編譯流程** (30 min)
   - 預處理 → 編譯 → 組譯 → 連結
   - 標頭檔 vs 原始檔
   - 編譯器的工作

3. **註解** (20 min)
   - 單行註解 `//`
   - 多行註解 `/* */`
   - 好的註解 vs 壞的註解

4. **程式碼風格** (30 min)
   - 縮排的重要性
   - 命名慣例
   - 空白的使用

5. **練習時間** (10 min)

### 關鍵程式碼片段

#### 片段 1：程式結構分解
```c
#include <stdio.h>  // ← 前處理指令

int main() {        // ← 主函式開始
    // 這裡是程式主體
    printf("Hi!\n");
    return 0;       // ← 回傳值
}                   // ← 主函式結束
```
> 完整範例：[examples/structure.c](examples/structure.c)

#### 片段 2：好的註解 vs 壞的註解
```c
// ❌ 壞的註解：說了等於沒說
int x = 5;  // 設定 x 為 5

// ✅ 好的註解：解釋為什麼
int x = 5;  // 預設重試次數，超過則放棄
```

4. **課堂練習** (30 min)
   - 小組討論
   - 一起追蹤程式

### 程式碼閱讀練習

#### 練習 1：這個程式輸出什麼？
```c
#include <stdio.h>

int main() {
    printf("A");
    printf("B");
    printf("C\n");
    return 0;
}
```

#### 練習 2：找出差異
```c
// 版本 A
printf("Hello\n");
printf("World\n");

// 版本 B  
printf("Hello\nWorld\n");
```
> 問題：這兩個版本的輸出一樣嗎？

#### 練習 3：這個程式有什麼問題？
```c
#include <stdio.h>

int main() {
    printf("Hello")
    return 0;
}
```
