## 📎 常見問題

**Q: int 和 long 有什麼差別？**
A: 主要是範圍不同。在大多數現代系統上，`int` 是 32 位元，`long` 是 64 位元。但這不是絕對的，取決於編譯器和平台。

**Q: 什麼時候用 float，什麼時候用 double？**
A: 一般推薦用 `double`，因為精確度較高。除非有特殊的記憶體限制，否則用 `double` 比較安全。

**Q: 變數名稱可以用中文嗎？**
A: 技術上某些編譯器支援，但強烈不建議。請使用英文命名。
