### 關鍵程式碼片段

#### 片段 1：整數除法的陷阱
```c
int a = 7, b = 2;
int result1 = a / b;          // 結果是 3，不是 3.5！
double result2 = a / b;       // 還是 3.0！
double result3 = (double)a / b; // 這才是 3.5
```
> 完整範例：examples/operators.c

#### 片段 2：前置 vs 後置遞增
```c
int x = 5;
int a = x++;  // a = 5, x = 6（先用再加）
int b = ++x;  // b = 7, x = 7（先加再用）
```

#### 片段 3：優先順序陷阱
```c
// ❌ 容易搞混
int result = 2 + 3 * 4;   // 是 14，不是 20

// ✅ 加括號更清楚
int result = 2 + (3 * 4);  // 明確表達意圖
```

## 📎 常見問題

**Q: 為什麼 `5 / 2` 是 `2` 而不是 `2.5`？**
A: 因為兩個運算元都是 `int`，C 語言會執行整數除法，直接捨棄小數部分。

**Q: `i++` 和 `++i` 效能有差嗎？**
A: 對整數來說幾乎沒有差異。在 C++ 中對於複雜物件可能有差異，但在 C 語言中可以忽略。

**Q: 為什麼不建議在同一個表達式中多次使用 `++`？**
A: 因為這會導致「未定義行為」(Undefined Behavior)，不同編譯器可能給出不同結果。
