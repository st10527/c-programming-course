5. **練習** (5 min)

### 關鍵程式碼片段

#### 片段 1：巢狀迴圈基本結構
```c
for (int i = 1; i <= 3; i++) {      // 外層：3 次
    for (int j = 1; j <= 4; j++) {  // 內層：每次 4 次
        printf("(%d,%d) ", i, j);
    }
    printf("\n");
}
// 內層總共執行 3 × 4 = 12 次
```
> 完整範例：examples/nested.c

#### 片段 2：break 和 continue
```c
// continue：跳過 3
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;  // 跳過本次
    printf("%d ", i);       // 輸出：1 2 4 5
}

// break：遇到 3 就結束
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;     // 結束迴圈
    printf("%d ", i);       // 輸出：1 2
}
```

### 關鍵程式碼片段

#### 片段 1：常見錯誤 - 分號
```c
// ❌ for 後面多了分號，迴圈主體不會重複
for (int i = 0; i < 5; i++);  // ← 注意這個分號！
{
    printf("%d ", i);  // 只會執行一次
}

// ✅ 正確寫法
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
```
> 完整範例：examples/mistakes.c

#### 片段 2：效率比較
```c
// ❌ 每次迴圈都計算 strlen
for (int i = 0; i < strlen(str); i++) { ... }

// ✅ 先算好長度
int len = strlen(str);
for (int i = 0; i < len; i++) { ... }
```

## 📎 常見問題

**Q: break 在巢狀迴圈中只跳出一層嗎？**
A: 是的，break 只會跳出最內層的迴圈。如果要跳出多層，可以使用旗標變數或 goto（不建議）。

**Q: 巢狀迴圈最多可以幾層？**
A: 語法上沒有限制，但實際上超過 3 層就會很難讀。如果超過 2 層，建議把內層迴圈抽成函式。

**Q: continue 和 break 哪個比較常用？**
A: break 比較常用。continue 有時候會讓邏輯變混亂，使用前請確認是否真的比 if-else 更清楚。
