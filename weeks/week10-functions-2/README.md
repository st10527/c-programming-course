   - 收斂性：問題必須越來越小

3. **經典遞迴範例** (40 min)
   - 階乘 n!
   - 費波那契數列
   - 整數位數和

4. **遞迴 vs 迭代** (20 min)
   - 任何遞迴都可以改寫成迴圈
   - 遞迴的優點：程式碼簡潔
   - 遞迴的缺點：效能開銷

5. **練習** (5 min)

### 關鍵程式碼片段

#### 片段 1：階乘（遞迴 vs 迭代）
```c
// 遞迴版本
int factorial(int n) {
    if (n <= 1) return 1;     // 基礎情況
    return n * factorial(n - 1); // 遞迴情況
}

// 迭代版本
int factorial_iter(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```
> 完整範例：examples/recursion.c

#### 片段 2：費波那契數列
```c
int fib(int n) {
    if (n <= 1) return n;        // fib(0)=0, fib(1)=1
    return fib(n-1) + fib(n-2);  // fib(n) = fib(n-1) + fib(n-2)
}
```

### 📝 遞迴展開範例

```
factorial(4)
├── return 4 * factorial(3)
│   ├── return 3 * factorial(2)
│   │   ├── return 2 * factorial(1)
│   │   │   └── return 1  ← 基礎情況
│   │   └── return 2 * 1 = 2
│   └── return 3 * 2 = 6
└── return 4 * 6 = 24
```

### 📝 費波那契呼叫樹

```
fib(5)
├── fib(4)
│   ├── fib(3)
│   │   ├── fib(2) → 1
│   │   └── fib(1) → 1
│   └── fib(2) → 1
└── fib(3)
    ├── fib(2) → 1
    └── fib(1) → 1

注意 fib(3) 被計算了 2 次，fib(2) 被計算了 3 次！
```

## 📎 常見問題

**Q: 遞迴和迴圈哪個比較好？**
A: 看情況。某些問題（如樹的走訪）用遞迴比較自然。但如果可以用迴圈簡單解決，迴圈通常效率更好。

**Q: 費波那契用遞迴很慢，為什麼還要教？**
A: 因為它是學習遞迴概念的好例子。實際上可以用「記憶化」(Memoization) 或動態規劃來優化。

**Q: 什麼時候會 Stack Overflow？**
A: 遞迴太深（通常數千到數萬層）或忘記寫基礎情況時。Stack 的大小通常是幾 MB。
