### 關鍵程式碼片段

#### 片段 1：for 迴圈
```c
// 印出 1 到 5
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// 輸出：1 2 3 4 5
```
> 完整範例：examples/loops.c

#### 片段 2：while 迴圈
```c
// 計算位數
int n = 12345;
int digits = 0;
while (n > 0) {
    n /= 10;
    digits++;
}
printf("位數: %d\n", digits);  // 5
```

#### 片段 3：do-while 迴圈
```c
int input;
do {
    printf("請輸入正數: ");
    scanf("%d", &input);
} while (input <= 0);  // 輸入不合法就重來
```

### 📝 追蹤表格範例

```c
int sum = 0;
for (int i = 1; i <= 4; i++) {
    sum += i;
}
```

| 步驟 | i | i <= 4 | sum | 說明 |
|-----|---|--------|-----|------|
| 初始 | 1 | true | 0 | 進入迴圈 |
| 第 1 次 | 1→2 | true | 1 | sum = 0+1 |
| 第 2 次 | 2→3 | true | 3 | sum = 1+2 |
| 第 3 次 | 3→4 | true | 6 | sum = 3+3 |
| 第 4 次 | 4→5 | false | 10 | sum = 6+4，結束 |

> 完整範例：examples/tracing.c

## 📎 常見問題

**Q: for 和 while 什麼時候用哪個？**
A: 如果你知道要重複幾次（例如 1 到 100），用 for。如果不知道次數（例如讀到某個值為止），用 while。

**Q: 為什麼 `for (int i = 0; i < 5; i++)` 而不是 `i <= 5`？**
A: `i < 5` 會執行 0,1,2,3,4 共 5 次，這是最常見的寫法。`i <= 5` 會執行 6 次（0 到 5）。

**Q: 忘記更新迴圈變數會怎樣？**
A: 會造成「無窮迴圈」，程式會永遠跑不完。可以用 Ctrl+C 強制停止。
