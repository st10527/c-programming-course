## 🎓 講課 A：指標與陣列

### 簡報大綱

1. **陣列名稱是指標** (30 min)
   - 陣列名稱代表第一個元素的位址
   - `arr` 等同於 `&arr[0]`
   - 為什麼函式中陣列會退化為指標

2. **指標運算** (30 min)
   - `ptr + 1` 移動一個元素的大小
   - `ptr - ptr` 求距離
   - 指標加減整數

3. **指標存取陣列元素** (30 min)
   - `*(arr + i)` 等同於 `arr[i]`
   - 用指標走訪陣列
   - 指標和索引的互換

4. **指標與字串** (25 min)
   - 字串常數與指標
   - `char *str` vs `char str[]`
   - 指標操作字串

5. **練習** (5 min)

### 關鍵程式碼片段

#### 片段 1：陣列名稱是指標
```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;       // arr 就是 &arr[0]

printf("%d\n", *p);       // 10 (第 0 個)
printf("%d\n", *(p+1));   // 20 (第 1 個)
printf("%d\n", *(p+2));   // 30 (第 2 個)
```
> 完整範例：examples/pointer_array.c

#### 片段 2：指標運算
```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;

// 以下三種寫法等價：
printf("%d\n", arr[2]);     // 索引寫法
printf("%d\n", *(arr + 2)); // 指標算術
printf("%d\n", *(p + 2));   // 指標變數
```

   - 忘記解參考

5. **總結與展望** (10 min)
   - 指標是 C 語言最強大也最危險的特性
   - 下學期 C++ 的預告

### 關鍵程式碼片段

#### 片段 1：Dangling Pointer
```c
// ❌ 危險！返回區域變數的位址
int* bad_function() {
    int local = 42;
    return &local;  // local 會在函式結束後消失！
}

int *p = bad_function();
printf("%d\n", *p);  // 未定義行為！
```
> 完整範例：examples/pointer_errors.c

#### 片段 2：安全的指標使用
```c
// ✅ 使用前檢查 NULL
void safe_use(int *p) {
    if (p == NULL) {
        printf("指標是 NULL！\n");
        return;
    }
    printf("值 = %d\n", *p);
}
```

### 📝 指標錯誤檢查清單

| 錯誤類型 | 症狀 | 預防方法 |
|---------|------|---------|
| 未初始化指標 | 隨機崩潰 | 宣告時初始化為 NULL |
| 解參考 NULL | Segfault | 使用前檢查 NULL |
| Dangling Pointer | 隨機錯誤 | 不要回傳區域變數位址 |
| 越界存取 | 覆蓋記憶體 | 檢查陣列邊界 |

## 📎 常見問題

**Q: `int *p` 和 `int arr[]` 作為函式參數有差嗎？**
A: 完全一樣，編譯器會把 `int arr[]` 當作 `int *arr`。

**Q: 指標可以加指標嗎？**
A: 不行，指標只能加減整數。但兩個指向同一陣列的指標可以相減（得到距離）。

**Q: 為什麼指標這麼難學？**
A: 因為指標需要同時理解「變數的值」和「記憶體位址」兩個層次。多畫記憶體圖會很有幫助。
