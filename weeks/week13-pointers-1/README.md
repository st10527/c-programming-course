3. **指標的宣告** (25 min)
   - 語法：`int *ptr;`
   - `*` 在宣告中的意義

4. **& 取址運算子** (20 min)
   - `&x` 取得 x 的位址

   - 將位址存入指標

5. **\* 解參考運算子** (25 min)
   - `*ptr` 取得指標指向的值
   - 透過指標修改值
   - `&` 和 `*` 是互逆操作

6. **練習** (5 min)

### 關鍵程式碼片段

#### 片段 1：指標基本操作
```c
int x = 42;
int *ptr = &x;      // ptr 儲存 x 的位址

printf("x 的值: %d\n", x);         // 42
printf("x 的位址: %p\n", &x);      // 0x7fff...
printf("ptr 的值: %p\n", ptr);     // 和 &x 一樣
printf("ptr 指向的值: %d\n", *ptr); // 42
```
> 完整範例：examples/pointers.c

#### 片段 2：透過指標修改值
```c
int x = 10;
int *ptr = &x;

*ptr = 20;  // 透過指標修改 x 的值
printf("x = %d\n", x);  // 20
```

### 關鍵程式碼片段

#### 片段 1：swap 函式
```c
// ❌ 傳值：交換的是複製品
void bad_swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

// ✅ 傳指標：交換原始值
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 5, y = 10;
swap(&x, &y);  // x=10, y=5
```

## 📎 常見問題

**Q: 指標有什麼用？為什麼不直接用變數？**
A: 指標可以讓函式修改外部變數、動態配置記憶體、操作陣列等。很多進階功能都需要指標。

**Q: `int *p` 和 `int* p` 有差嗎？**
A: 語法上完全一樣。但建議用 `int *p`，因為 `int* p, q;` 中 q 不是指標，容易誤解。

**Q: 為什麼解參考 NULL 會程式崩潰？**
A: NULL (0) 不是合法的記憶體位址，嘗試讀寫位址 0 會觸發作業系統的保護機制（Segmentation Fault）。
